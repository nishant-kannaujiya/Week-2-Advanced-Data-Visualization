# Week 2 – Data Visualization

## Project Overview

This project was completed as part of my internship training. The objective of this project is to analyze the given dataset and create meaningful visualizations using Python.

## Tools & Technologies

- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Dataset

The project uses a CSV dataset containing the required business data for analysis.

## Visualizations

The project includes the following visualizations:

1. Overall Revenue Analysis
2. Category-wise Revenue
3. Region-wise Revenue
4. Discount vs Revenue
5. Additional exploratory visualizations

## Project Files

- `Week_2_Data_Visualization.ipynb` – Complete analysis, Python code and visualizations
- `dataset.csv` – Dataset used for the analysis
- `README.md` – Project documentation

## Conclusion

The analysis provides useful insights from the dataset through exploratory data analysis and visualizations. These insights can help in understanding revenue patterns, category performance, regional performance and the relationship between discount and revenue.
